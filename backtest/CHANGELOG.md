# 歷史回測參考：規則紀錄

規則與門檻寫在 `config.yaml` 的 `backtest` 區塊。**必須先 commit 規則，才能跑回測**；看過結果之後若要修改，
在這裡新增帶日期的段落，寫明改了什麼、為什麼改，並保留舊的結果檔與 commit 紀錄，不可只留最好的版本。

## 2026-10-17：初版（回測前寫定）

- 使用者修改核心原則第 4 條：允許依歷史回測產生參考分數與「買進／持有／賣出參考」標示。
- 衡量：每個月底（2021-06-30 起）以當時可得資料計算 V1 綜合分數，之後 3、6、12 個月相對加權報酬指數的超額報酬。
- 分數區間：[0, 0.4)、[0.4, 0.6)、[0.6, 0.8)、[0.8, 1]。
- 標示規則：6 個月超額報酬的 95% 區塊自助法信賴區間（區塊 = 股票 × 年度，1000 次）整段大於 0 為買進參考、
  整段小於 0 為賣出參考、其餘為持有參考；樣本少於 30 不標示。
- 樣本：`app.watchlist` 的 50 支（今天仍上市，有倖存者偏差）；與每日匯出相同，不抓同業資料。
